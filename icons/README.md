# Icons

SVG icon assets used by the `breezewidget` package.

## Source

Icons are taken from [Tabler Icons](https://tabler.io/icons), a free open-source
icon set with 6000+ icons.

- Project: <https://tabler.io/icons>
- Repository: <https://github.com/tabler/tabler-icons>

## License

Tabler Icons are released under the MIT License. See the upstream license at
<https://github.com/tabler/tabler-icons/blob/main/LICENSE>.

## Layout

- `outline/home-2.svg` — fixture used by the SVG rendering tests.
- Built-in runtime icons are bundled in `src/breezewidget/icons/outline/`.
